##Firmware:

This thingamajig uses QMK firmware, and its powered by the hopes and dreams of 3 chatbots that verified that the code works in the first place. It displays what i type, and when i press enter, it checks if the code i inputted is correct.

##BOM:

Heres everything that should probably make this thing. Its pretty simple.

- 5x 1N4148 DO-35 Diodes.
- 1x 0.91" 128x32 OLED Display
- 1x XIAO RP2040
- 1x Case (3 printed parts)
- 4x Cherry MX Switches
- 4x DSA Keycaps
- 4x M3x16mm screws
- i assume im not missing anything else.
